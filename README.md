# Crypto WS (BTC + ETH)

Ready-to-deploy project:
- backend: FastAPI service that listens to Binance public websocket and broadcasts to connected clients
- frontend: simple static HTML client showing live BTC/ETH prices

Follow backend/README.md and frontend/README.md to run locally.

NOTE: Update frontend/index.html - replace 'YOUR_BACKEND_DOMAIN' with your backend domain after deployment.
